# 对话分支插件 dialog_fork

在 AstrBot 的同一聊天窗口内为当前 LLM 对话创建分叉点，并在之后跳转回任意分叉继续对话。

## 功能

- `/fork [分叉点名称] [注释]`：基于当前对话创建分叉点。不填名称时使用当前时间戳作为名称。
- `/jump <分叉点名称>`：跳转到指定分叉点，后续对话会接在该分叉点对应的 AstrBot conversation 后面。
- `/forkpoint-rename <旧分叉点名> <新分叉点名>`：重命名分叉点。
- `/forkpoint-list`：列出当前聊天窗口中创建过的分叉点。
- `/forkpoint-remove <分叉点名称>`：删除指定分叉点。若当前正处于该分叉点，会拒绝删除。

所有参数都按空格分隔，因此分叉点名称和注释都不能包含空格。分叉点名称大小写敏感。

## 行为说明

- 分叉点按聊天窗口共享。同一个私聊、群聊或 WebChat session 下创建的分叉点可以互相跳转。
- 插件使用 AstrBot 原生 conversation 保存分叉内容，不会把插件命令写入 LLM 历史。
- “段对话”按用户主动发送给 LLM 的 user 消息数量计算，以 `/` 开头的命令消息不计入。
- 执行配置项中的重置命令后，插件会在命令回复发送完成后清空当前聊天窗口的分叉点。默认监听 `/reset` 和 `/new`。
- 如果某个分叉点对应的 AstrBot conversation 已被外部删除，`/jump` 时会提示“不存在或已失效”，并清理该分叉点记录。

## 配置

在 AstrBot 管理面板中可以配置：

- `reset_commands`：执行后清空分叉点的命令列表，默认 `["/reset", "/new"]`。
